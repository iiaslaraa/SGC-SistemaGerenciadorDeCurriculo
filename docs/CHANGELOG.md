# Changelog

## [1.0.0] - 2026-07-11

### Adicionado

* Estrutura inicial do Sistema de Gerenciamento de Currículos (SGC).
* Interface web desenvolvida em HTML5 e CSS3.
* Integração com banco de dados MySQL utilizando PHP.
* Cadastro de candidatos.
* Cadastro de endereços.
* Cadastro de formação acadêmica.
* Cadastro de experiências profissionais.
* Cadastro de certificações.
* Cadastro de cursos de qualificação.
* Listagem de candidatos cadastrados.
* Visualização de currículos.
* Edição de informações dos candidatos.
* Exclusão de candidatos e registros relacionados.
* Arquivo de conexão com o banco de dados.
* Script SQL para criação e população do banco de dados.
* Modelo relacional desenvolvido no MySQL Workbench.
* README completo do projeto.
* Documentação técnica.
* Manual de instalação.
* Manual do usuário.

### Melhorias

* Organização da estrutura do projeto para publicação no GitHub.
* Padronização da documentação.
* Revisão da estrutura do banco de dados.
* Melhoria na organização dos arquivos do projeto.

### Tecnologias

* PHP
* MySQL
* HTML5
* CSS3
* SQL
* phpMyAdmin
